## 0.2.0 面对面 · 2026-11-03

| 使用场景 | 结果 |
|---|---|
| 从界面按住、松手、收音、翻译 | 两次真实触摸驱动，机身扬声器播放固定句，机身麦克风分别取得 24,958 和 34,558 个样本。中文「我想买两张票」得到「Je voudrais acheter deux billets.」，反向得到「我想要两张票。」 |
| 千问服务 | Fold5 通过 20 条受控语音，两个方向各 10 条，均保留一条识别和译文。短法语问候发生误识别，一句请求重复的话被多听成带数字。车次问题在中文里没指定车型，译成了巴士。固定录音的重复测试不代表一般语音准确率或冷启动延迟 |
| 朗读和打字 | 两种语言的千问合成声音均在蓝牙媒体路由完成播放。使用无障碍接口在实际输入框输入法语车次句，断言屏幕显示「火车明天早上发车。」 |
| 展开、折叠与导航 | 外屏实测 1172×2748。临时切换系统折叠状态，内屏实测 2200×2480，对面旋转 180°，测试后恢复外屏。自动经过词本、出行分类、历史、设置和诊断 |
| 工程 | 26 项主机接口和安卓测试通过，Lint 零错误。主程序与测试包通过 v2 签名校验，手机上的主包与本地构建 SHA-256 一致 |

## 下次接入 X Fold5

1. 在受控样本下补测播放捕获的静音对照、拒绝和共享中途停止，以及耳机录音中途断开后的恢复。
2. 用两个方向试按住、取消、松开发送与本地重播，并测折叠变化。新结果按本次应用与系统版本归档。

## 后续开发顺序

- 单麦克风基线可复现后，接入一家能完成中文和法语识别、翻译、合成的真实服务，跑二十轮面对面对话，再做自由监听、抢话和回声处理。
- 文件导入、语音消息和输入法单独验收。先用可识别的受控语音检查采集来源。
- 调试账户的音频采集权限目前只在系统权限列表中得到确认。两款通话应用均需对端听音。采到对方、让对方听到译音分别记录。
- 多副耳机先测试同播，再测独立输出和两个独立麦克风。按实际组合开启对应能力。
