## 下次接入 X Fold5

1. 对已签名的调试 APK 执行覆盖安装。用设备测试接口验证首页启动及只读状态。
2. 首次采样由使用者同意麦克风权限。分别用手机和一副耳机采十秒，记录请求输入、实际端口、样本数、峰值和系统静音状态。
3. 测试音单独记录输出。选择「应用测试音」做一次系统播放共享，随后测试拒绝及共享中途停止。
4. 用两个方向试按住、取消、松开发送与本地重播，然后测试折叠和耳机断开。导出脱敏报告填入矩阵。

## 后续开发顺序

- 单麦克风基线可复现后，接入一家能完成中文和法语识别、翻译、合成的真实服务，跑二十轮面对面对话，再做自由监听、抢话和回声处理。
- 文件导入、语音消息和输入法单独验收。先用可识别的受控语音检查采集来源。
- 调试账户的音频采集权限目前只在系统权限列表中得到确认。两款通话应用均需对端听音。采到对方、让对方听到译音分别记录。
- 多副耳机先测试同播，再测独立输出和两个独立麦克风。按实际组合开启对应能力。
