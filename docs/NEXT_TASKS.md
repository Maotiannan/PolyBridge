## 0.5.3 候选 · 轻声回声的首次匹配

2026-11-04 在 Fold5 上补测 0.5.2：普通抢话只生成两条正确记录，停止播报用时 367 毫秒；轻声加持续背景声的两次测试均多生成了一句。第二次排错确认多余内容出现在只有第二句播报回声、没有新的人声的阶段。

电脑用随包语音复现：回声比背景声略响时，旧算法等待高可信度的单帧匹配，前半句一直没有建立回声参考。0.5.3 增加连续 40 毫秒的延迟与增益一致性确认，只有扣除匹配后剩余能量不超过实测背景水平，才允许提前建立参考。没有新增用户开关或按词语丢弃短回答。

四段中法录音的相关回声残留指标为 0.0146、0.0195、0.0308、0.0237，均低于测试上限 0.045。首个样本修复前为 0.5796。同一噪声条件下，另一位轻声发言者在前半秒的保留投影分别为 0.911、0.969；这是固定 PCM 的相关指标，不是文字准确率。53 项电脑测试全部通过，Lint 零错误、29 项既有提示。

**手机仍为 0.5.2，0.5.3 尚未安装。** 更新前 USB 断开，因此不宣称新回声补丁已通过真实千问。

接线后按顺序执行：

1. 读设备版本并安装 0.5.3，核对设备与电脑安装包摘要。
2. 连续复测普通、轻声加底噪两种抢话，逐句检查没有多余回声记录，检查轻声句首。
3. 在同一最终安装包重跑纯雨声、八组换气法语和另一应用的真实字幕，确认停止后全文仍在。
4. 测试结束停止所有采集，恢复本轮临时 USB 常亮设置为原值 `0`（当前为 `2`，因断线尚不能恢复），回到正常应用。办公室扬声器此前读数为静音 `0/150`，不应误称已经设成 `1/150`。
