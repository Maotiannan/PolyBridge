# 工程结构

自由监听把播放端真实使用的 24 kHz 语音与麦克风帧比较。设备提供回声消除器时将其接到录音会话，应用另外匹配传输延迟、直达声和短反射，依据播报前的环境声音决定是否抢话。播放器在输出设备实际接收静音帧后才提交译音，显示的进度取自已消耗的语音帧。被打断的句子仍然保留在本机历史中。

手动重播与自动对话分路可独立配置。应用按句子、目标语言、译文、模型与音色索引 8 MiB 内存音频缓存。自由监听已经返回的语音直接进入缓存，修改文字会生成新键。校对和清空操作在保存本地快照成功后才更新界面。撤销清空会合并期间新增的句子，迟到的翻译结果不能重新创建已删除的句子。

在背景声持续的场景，回声消除器对照麦克风与实际播放波形。延迟相符且剩余能量可以由已测背景声解释时，重新学习声学路径的音量。只有同时满足波形匹配和能量条件的帧才按这条规则抑制。

| 边界 | 职责 |
|---|---|
| core / AudioEvidence | 音频能量、有效样本、静音与结束原因、实际端口和诊断记录 |
| core / ProbeReport | 有版本的报告、构建指纹摘要、JSON 与 Markdown。不包含原始音频 |
| core / Conversation、SpeechTranslation | 录音、识别、翻译与纠错状态，恢复中断、区分当前会话与历史；供应商无关的识别、翻译、合成接口及单声道 WAV |
| provider / qwen | 百炼地区与业务空间、识别和翻译请求、自然声音合成、超时和错误分类。带签名的音频地址仅用于下载，下载不携带 API Key |
| app / audio | 音频设备与蓝牙协议、Android 录音和播放接口、用户启动的前台采样服务 |
| app / PolyBridgeApp | 同一时间只开放一个采样会话，结束结果按会话标识接收。已完成诊断与最近对话写入应用私有存储 |
| app / ConversationTranslator、TranslationSettings | 在应用进程处理松手后提交的句子，保留已识别的原文供重试；凭据用 Android Keystore AES-GCM 加密，不进入导出报告 |
| app / ui | 对话、离线词本、历史和设置；宽屏旋转分区；系统语音在千问朗读不可用时提供降级。词本读音随应用安装 |
| app / MainActivity | 用户权限、逐次系统播放捕获授权、服务启动和系统文件选择器导出 |

采样开始前记录可恢复的中断状态。正常结束时同时更新会话和诊断记录。滞后的重复回调不会覆盖新会话。保留最近 40 条诊断和 100 条对话。0.1.x 历史升级后仍可查，旧示例保留标签。只有面对面按住期间暂存最长 30 秒 PCM，取消、静音和错路由均不会上传。进程被杀后只保留已有文字。

普通麦克风和播放捕获共用度量与结束判定。前台服务只带本次需要的服务类型，麦克风和播放共享由不同的用户动作启动。退出或系统撤销后释放录音与共享对象。报告中最近一次测试音的实际输出和每次采样的实际输入各自独立。

## 自由监听、消息与声音输出

| 模块 | 处理范围 |
|---|---|
| core / LiveConversation、ReconnectingLiveSession | 实时字幕、最终译文、终止原因和有上限的连接恢复。旧连接的迟到事件与中断期间的声音不进入新会话 |
| provider / qwen / QwenLiveSession、RealtimeEvents | 16 kHz 音频经两个固定目标语言的连接发送。结合源语言识别、句子和响应编号归集译文与 24 kHz 译音，只提交匹配的翻译方向 |
| app / audio / LiveDesk、PlaybackFloor | 按实播语音消除回声并暂存开头几个音节。发现另一种声音时先短暂调低朗读，从设备真正静音的时刻计时。持续的新声音或与本句无关的识别结果可以打断朗读，疑似微弱人声也会送交识别 |
| app / audio / PlaybackRouting、HeadsetPreferences | 确认实际输出后按系统媒体音量播放。手动指定的耳机未匹配时保持静音。设备分配使用每次安装独有的散列标识 |
| app / audio / CaptionApps、ProbeService、LiveDesk | 用户选择可启动的来源应用。前台服务持有本次播放共享许可，按来源 UID 和媒体用途过滤 PCM，送入中法两个自动识别方向。字幕使用纯文本输出，不通过扬声器读回所听内容 |
| app / ui / ScreenCaptions、AppCaptionPanel | 前台服务管理悬浮窗。显示部分原文、逐步更新的译文、最近完整一句和无声状态。字幕卡的位置与来源应用分别保存，关闭或系统撤回许可时释放窗口和音频会话 |
| app / ui / CallAssistPanel、audio / TranslatedAudioShare | 机主说中文后生成法语，可在本机播放，或显式分享私有缓存中的只读语音。通话上行仍须另行验证 |

自由监听、长按和系统播放共享互斥。语音消息共享只申请所选应用允许采集的媒体用途，通话音轨仍须单独验收。

音量图形的输入取自回声处理前的 20 毫秒 PCM，界面最多每 65 毫秒接收一次新值。按住说话期间，手势由第一次按下的指针持有。跨过按钮上边缘的取消区只改变松手行为，回到按钮恢复发送。折叠屏下半区预留系统手势空间，面对面页单独管理临时系统栏。应用弹窗共用窄屏底部面板和宽屏居中面板，系统授权仍通过 Android 本身完成。
