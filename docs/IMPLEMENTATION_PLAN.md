# 首版实施计划

需求以根目录 PRD v1.0 和启动说明为准。2026-11-03 核对的起点是两份需求文件与一份启动说明，没有现成应用和 Git 历史。首轮选择普通 Android 应用，诊断和面对面两条线共享收音实现。已授权在电脑上开发，真机安装及录音留到设备再次接入后。

| 工作包 | 代码位置 | 可重复验收 |
|---|---|---|
| 工程与版本 | Gradle Wrapper、版本目录、app、core | Android 16 编译，构建调试安装包 |
| 音频度量和报告 | core 的信号统计、报告、状态测试 | 静音、无数据、系统静音、部分采集和中止分别给出结果，报告只含白名单信息 |
| 安卓诊断 | app 的 audio 和 diagnostics | 显式启动手机或耳机麦克风、独立测试音和逐次授权的播放捕获，记录活动路由，导出 JSON 或 Markdown |
| 双屏面对面 | core 的 Conversation、app 的 ui/ConversationPanel | 两种语言方向、按住/取消/发送、示例结果和重播。真实云端识别及翻译单独验收 |
| 交付 | README、能力矩阵、CI、设备测试 | 运行单元接口测试与 lint，编译设备测试包，验签 APK。真机项目保持待测 |

首个测试用已知样本调用音频统计接口。之后用播放捕获的本应用测试音作为阳性对照。手机与单副耳机的十秒收音是下次接机的起点，通话实验以两端知情和真实听音为前提。
