### 面对面 0.4.0 的测量方法

1. 在两种采样率下，把真实中文和法语词本录音叠在一起。改变回声的衰减、延迟和反射，检查纯回声、打断时间和开头是否保留。
2. 将已知输入送入应用正式使用的自由监听管线，读安卓播放器的实际设备与播放头，在主线程核对停止输出的时间。真实云端另测，检查最终双语记录中有没有多出的回声句。
3. 机身扬声器保持最低非零档。机身麦克风先听房间、再听本机译音，最后让独立的另一句声音加入，检查提前误停、打断延迟、输入和输出电平。该项本地测试只保存读数。
4. 在历史页实际点击重播、纠错和保存，从手机读取播放设备、播放到的帧数与本地持久化结果。整库清除使用专用安卓虚拟设备上的记录。
