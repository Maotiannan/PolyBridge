# 音频验收矩阵

本表以这台 Fold5 的实测为准。主机上的合成样本仅覆盖接口和判定逻辑。下次接机时先做前三项。

| 编号 | 操作 | 通过依据 | 真机状态 |
|---|---|---|---|
| P0-01 | 麦克风页选系统默认，对手机说话十秒 | 样本数与时长相符，声音有能量，实际输入是手机麦克风 | UNVERIFIED |
| P0-02 | 连一副耳机，选择耳机输入，说话十秒 | 实际输入指向耳机。遮住手机麦克风后耳机侧仍有信号 | UNVERIFIED |
| 对照 | 播放捕获页选应用测试音，逐次同意共享 | 同一应用发出已知短音并捕获有效信号。另做静音对照 | UNVERIFIED |
| P0-03 | 指定耳机收音，再单独选手机扬声器播测试音 | 记录各次真实路由及人耳听音。并发分路另测 | UNVERIFIED |
| P0-04/05 | 连接两副耳机 | 配对、连接、同时听同一声音、分开听两种语言、两路独立收音逐项记录 | UNVERIFIED |
| P0-06/07 | 分别播放已知内容的微信或 WhatsApp 语音条 | 各自目标与版本、可识别信号和来源对照。静音原因待查 | UNVERIFIED |
| P0-08/09/10 | 双方同意的测试通话 | 微信和 WhatsApp 的本地收音、对方声音、译音上行与听到的原声分别验收 | UNVERIFIED |
| P0-11 | 录音中断开耳机、停止共享、锁屏或折叠 | 报告记录设备变化/撤销/中断，返回应用可继续下一次操作 | UNVERIFIED |
| P0-12/13 | 调试账户或独立高权限研究 | 普通应用实验后单独开展，真实对端验证 | UNVERIFIED |

系统静音标志读取不到时显示“无法读取”。能量接近零可能是环境安静、音频来源选择或播放方策略等多种原因，不能单凭静音断定厂商禁止捕获。端口编号仅用于本次路由比较。
