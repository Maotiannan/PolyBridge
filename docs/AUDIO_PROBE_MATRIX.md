# 音频验收矩阵

本表记录 2026-11-03 在这台 Fold5 上的实测。测试使用一副蓝牙耳机。主机合成样本另计。

| 编号 | 操作 | 通过依据 | 真机状态 |
|---|---|---|---|
| P0-01 | 用机身麦克风收音十秒 | 样本数与时长相符，实际输入是手机麦克风 | 通过。0.1.0 默认输入及 0.1.1 耳机连接时指定机身输入，均为端口 19 |
| P0-02 | 连接一副耳机并指定其麦克风 | 请求与实际输入一致，收到有效声音 | 0.1.1 路由和采样通过。请求与实际均为蓝牙通话输入 869，10004 ms，159360 个样本。独立声学隔离程度未测量 |
| 对照 | 共享当前应用，采集本应用测试音 | 已知短音播放时有有效样本，记录播放和捕获端口 | 阳性对照通过。实际蓝牙媒体输出 859，系统播放捕获输入 883，10002 ms。单独的静音对照待测 |
| P0-03 | 指定耳机收音，再单独选手机扬声器播测试音 | 记录各次真实路由及人耳听音。并发分路另测 | UNVERIFIED |

| P0-06/07 | 分别播放已知内容的微信或 WhatsApp 语音条 | 各自目标与版本、可识别信号和来源对照。静音原因待查 | UNVERIFIED |
| P0-08/09/10 | 双方同意的测试通话 | 微信和 WhatsApp 的本地收音、对方声音、译音上行与听到的原声分别验收 | UNVERIFIED |
| P0-11 | 录音中断开耳机、停止共享、锁屏或折叠 | 报告记录设备变化/撤销/中断，返回应用可继续下一次操作 | UNVERIFIED |
